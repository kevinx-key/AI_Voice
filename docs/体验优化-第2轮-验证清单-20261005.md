## 一、本轮改了什么

### 1) 录音状态：一次按键立刻录音；整理/注入不再阻塞下一次录音
根因（今天日志证实）：`run_session` 收尾时会**清空命令通道里残留的 Press/Release**，把"上一段还在识别/整理/注入时你已经按下的下一次 Press"一起丢掉 → 必须按两次。
改法：
- **删掉收尾清管道**（`src/main.rs`）：新 Press 不再被丢；会话结束立即接受下一次。
- **整理 + 注入移到独立"输出线程"**（`src/main.rs` 新增 `OutputJob`/`output_loop`）：录音线程在会话结束只做"识别尾段"（~50~100ms）就把原文丢给输出线程，**马上能开始下一次录音**；整理（本地大模型，几百 ms~秒级）和 Ctrl+V 注入都在后台串行执行，不再占用录音线程。
- 效果：按住说话期间一直录到松手；松手瞬间即可再次按 F9 立刻录音；上一段的整理/注入在后台完成，不影响当前录音。

### 2) 一个安装包搞定
- `installer/listen.iss` 的 `[Run]` 新增：安装时**静默运行随包携带的 fork 安装器**（`/S`，复用注册表里的旧安装目录），随后再拉首启向导。
- 以后只需运行 **`listen-0.1.0-setup.exe` 一个包**，语音端 + 输入法端一起装好。

### 3) 每种语言只保留一种最佳输入法
根因：方案包 `rime-ice/` 自带 9 个方案（rime_ice + t9 + 6 个双拼…），被平铺进用户目录后都变成"可选输入法"。
改法（`src/rime/mod.rs`）：新增 `SKIP_SCHEMA_FILES` 白名单排除——**不铺** `t9 / radical_pinyin / double_pinyin*(6 个) / default.yaml`。
- 保留：中文 `rime_ice`；英文 `melt_eng`（混输）/`easy_en`；日文 `jaroomaji`。
- 重新部署后，用户目录里同语言多余的方案会被**自动清理**（陈旧文件清除逻辑），方案选单里每种语言只剩一个。

### 4) 语言栏右键菜单（你看的那个）终于改对地方
**你要的"设置文件"位置**（这是编译进 `weasel.dll` 的，不是运行时配置文件）：
- 菜单定义：`K:\K3R-voice\WeaselTSF\WeaselTSF.rc`（`IDR_MENU_POPUP` / `IDR_MENU_POPUP_HANS` / `IDR_MENU_POPUP_HANT`）——12 项就在这。
- 菜单显示逻辑：`K:\K3R-voice\WeaselTSF\LanguageBar.cpp`（右键 `OnClick`、`InitMenu`）。
- 命令处理：`LanguageBar.cpp` 的 `WeaselTSF::_HandleLangBarMenuSelect`。
- 编译产物：`weasel.dll` → 安装到 `C:\Windows\System32\weasel.dll`（x64）+ `C:\Windows\SysWOW64\weasel.dll`（x86）。

**为什么以前多次没生效**：① 之前改的是 `K:\K3R-voice\WeaselServer\WeaselTrayIcon.cpp`——那是**托盘（通知区）**菜单，跟你在任务栏「中」图标上右键看到的**不是同一处**；② 这枚菜单编在 `weasel.dll` 里，会被很多进程加载，改完必须重装 fork 并重启进程/系统才会刷新。
改法：不改 UTF-16 的 `.rc`，直接在 `LanguageBar.cpp` 里用代码构建菜单 `BuildListenMenu()`，右键/`InitMenu` 都用它 → 恰好 3 项：`设置` / `语音引擎：<未连接|待机|就绪|挂起|启动中>` / `开启语音|关闭语音`。
