## 0. 一句话目标

做一个**三端（Windows / macOS / Linux）原生、无 Python、体积小、可靠**的"按住热键说话 → 出字"输入工具；
**本地识别**与**云端识别/整理**由用户在托盘菜单里自己选，不锁死。

---

## 1. 范围

### 做
- 全局热键 PTT（按下开始录、松开结束），**不吞键**（不影响 F9 在原应用里的功能）
- 本地 ASR：sherpa-onnx + SenseVoice（中文/英文，int8 约 230MB）
- 云端 ASR：OpenAI 兼容 `/v1/audio/transcriptions`（BYOK：地址 + 密钥）
- 可选文本整理：关闭 / 云端 OpenAI 兼容 chat/completions（本地 LLM 见二期）
- 文本注入：剪贴板 + 模拟 Ctrl/⌘+V，注入后恢复原剪贴板；`Shift+F9` 撤销并换 ASR 原文
- 托盘常驻 + 状态图标（待机/录音/识别/整理/注入）+ 托盘菜单
- 配置 `config.toml`（绿色，exe 同级）、日志 `logs/app.log`（轮转）、单实例、开机自启
- 静音防线（RMS 阈值）、录音上限 25s、失败自动回退（LLM 超时→原文；云不可用→本地）
- CLI：`--once <wav>`、`--selftest`、`--no-tray`、`--config <path>`（自动化回归用）

### 不做（本期）
- 图形设置窗口（用托盘菜单 + 配置文件）
- 手机端 / 网页端 / TTS / 语音助手类功能
- macOS 代码签名与公证（二期，需要 $99/年 Apple 开发者账号）
- 本地 LLM 推理（二期，用 llama-server 子进程方案）

## 2. 已拍板的决策（含被否决方案，便于追溯）

| # | 决策 | 理由 | 被否决的方案 |
|---|------|------|------------|
| 1 | **自研纯 Rust 客户端** | 完全可控、壳可做到 10~20MB 级、无 Node/WebView/Python | ① 打包现有 Python 版（不满足"无 Python/三端"）；② fork Handy（MIT/32k★，中文 SenseVoice 已内置，但云端 ASR 缺、要背 Tauri+React 栈）；③ fork OpenWhispr（Electron，安装包 254MB）；④ Tauri 自研（多一层 WebView，体积/复杂度都不划算） |
| 2 | **Windows 优先**，mac/linux 二期 | 最快拿到可用产物；三端热键/注入/托盘是三套实现，一次做完验证压力大 | 三端并行 |
| 3 | 本地 ASR 用 **SenseVoice-small int8**（230MB） | 中文/英文效果好、CPU 极快、体积可控；FunASR-Nano（1.5GB）作为"高精度可选"放二期 | 保持 FunASR-Nano 内置（1.5GB）；Whisper（中文标点/术语偏弱） |
| 4 | 云端走 **OpenAI 兼容协议** | 一套客户端可对接：自建服务器 / 公司内部服务 / 云厂商，改配置即切 | 绑定某一家云厂商 SDK |
| 5 | **热键自写低级钩子**（Windows `WH_KEYBOARD_LL`） | `global-hotkey` 底层是 `RegisterHotKey`，会**全局吞掉 F9**（Excel 重算、Word 更新域全废）；自写钩子可"不吞键 + 拿到按下/松开" | `global-hotkey`（吞键）、`rdev`（3 年停更、Win11 25H2 钩子失效 issue） |
| 6 | **托盘菜单 + config.toml**，不做 GUI | 无 winit/渲染栈依赖，体积最小 | egui 设置窗（+5~15MB、+2~3 天） |
| 7 | 模型**首次运行下载**（hf-mirror 优先、modelscope 兜底）+ 支持手动放置 | 安装包才可能小（~20MB 级）；模型 230MB 不进安装包 | 模型随包（安装包 250MB+） |
| 8 | 整理 LLM **默认关闭** | 省 2.6GB 与 GPU 依赖；云端整理按需开 | 默认开本地 LLM |

## 3. 技术栈（版本与调研结论）

| 位置 | crate / 版本 | 调研结论与坑 |
|------|-------------|-------------|
| 热键 | 自写（`windows` crate） | Windows：`SetWindowsHookExW(WH_KEYBOARD_LL)`，回调里**不拦截**（`CallNextHookEx` 原样返回），记录按下/松开；`GetAsyncKeyState(VK_SHIFT)` 判 Shift。需独立线程跑消息循环 |
| 录音 | `cpal` 0.18 | 0.18 起原生 PipeWire/PulseAudio；**设备默认采样率常不支持 16kHz** → 按设备默认配置打开，再自行重采样 |
| 重采样 | `rubato` 5（纯 Rust） | 16k 单声道：多声道采集→取单声道→降采样 |
| 本地 ASR | `sherpa-onnx` 1.13.8（官方） | 默认**静态链接**；build 时若未设 `SHERPA_ONNX_LIB_DIR` 会**联网**从 GitHub Releases 下载预编译库（win-x64 静态归档 117MB，压缩）→ 国内需镜像/预下载。SenseVoice 有官方 example |
| 云 ASR | `reqwest`（rustls） | OpenAI 兼容 `/v1/audio/transcriptions`，multipart 上传 wav |
| 注入 | `arboard` 3.6 + `enigo` 0.6 | 剪贴板写入 → 模拟 Ctrl+V → 延时后恢复原剪贴板；**注意 arboard 的剪贴板内容由本进程托管，粘贴完成前不能退出** |
| 托盘 | `tray-icon` 0.25 | Windows 用 Shell_NotifyIcon；**图标自己画**（RGBA 缓冲区画圆点），避免引入 `image` crate |
| 配置 | `serde` + `toml` | 绿色：exe 同级 `config.toml`，缺失则写默认 |
| 日志 | `tracing` + `tracing-appender` | 文件轮转 + 控制台（`--no-tray` 调试用） |
| 单实例 | 自写 | Windows：`CreateMutexW` 命名互斥体（`single-instance` crate 已 6 年未更新） |
| 自启 | 自写 | Windows：`HKCU\...\Run` 注册表项（`auto-launch` 可作备选） |
| CLI | `clap` 4 | `--once/--selftest/--no-tray/--config` |
| 模型下载 | `reqwest` + `sha2` | hf-mirror.com → modelscope.cn 兜底；带进度；校验大小/哈希；支持 `models/` 手动放置 |

**构建环境**：`rustup`（清华/中科大镜像） + `crates.io` 镜像（rsproxy.cn 或清华） + MSVC 工具链（本机 VS 2026 已有） + `+crt-static`（免装 VC++ 运行库）。

## 4. 架构

### 4.1 数据流

```
[按住热键] → [录音 16k 单声道] → [静音防线/RMS] → [ASR 后端: 本地 SenseVoice | 云端 API]
          → [整理 后端: 关闭 | 云端 LLM] → [剪贴板+Ctrl+V 注入] → [托盘状态]
```

### 4.2 目录结构

```
K:\AI_Voice_rs\
├─ Cargo.toml
├─ config.toml              # 运行时配置（绿色，exe 同级）
├─ models\                  # 模型（首次运行下载或手动放置）
│   └─ sense-voice\         # model.int8.onnx + tokens.txt
├─ logs\                    # app.log（轮转）
├─ src\
│   ├─ main.rs              # 入口：CLI 解析、单实例、启动状态机
│   ├─ config.rs            # 配置结构 + 读写 + 默认值
│   ├─ state.rs             # 状态机（idle/recording/transcribing/polishing/injecting/error）
│   ├─ hotkey\
│   │   ├─ mod.rs           # 热键抽象（按下/松开/Shift 组合）
│   │   └─ windows.rs       # WH_KEYBOARD_LL 实现（不吞键）
│   ├─ audio.rs             # cpal 采集 + rubato 重采样 + RMS 静音防线
│   ├─ asr\
│   │   ├─ mod.rs           # trait AsrBackend + 工厂（按配置选本地/云）
│   │   ├─ local.rs         # sherpa-onnx SenseVoice
│   │   └─ cloud.rs         # OpenAI 兼容 transcriptions
│   ├─ polish.rs            # trait Polisher（Noop / 云端 chat completions）
│   ├─ inject.rs            # arboard + enigo（含剪贴板恢复、Shift+F9 换原文）
│   ├─ tray.rs              # tray-icon：状态图标 + 菜单
│   ├─ models.rs            # 模型下载/校验/路径解析（hf-mirror → modelscope）
│   └─ selftest.rs          # 25 条音频回归（ASR 精度/耗时）
├─ installer\
│   ├─ ai-voice.iss         # Inno Setup 脚本
│   └─ build.ps1            # 打包：cargo build --release → zip / iss
└─ tools\                   # 调试脚本（音频设备枚举、注入靶窗口等）
```

### 4.3 模块职责与接口

```rust
// asr/mod.rs
pub trait AsrBackend: Send {
    fn name(&self) -> &str;
    fn transcribe(&self, samples: &[f32], sample_rate: u32) -> anyhow::Result<String>;
}

// polish.rs
pub trait Polisher: Send {
    fn polish(&self, text: &str) -> anyhow::Result<String>;  // 超时/失败 → 调用方回退原文
}
```

- 后端在**启动时按配置实例化**，托盘切换后**热重建**（本地模型常驻，避免每次加载 12s）
- 所有后端调用带超时（云 ASR 默认 15s、云整理默认 5s），失败**降级**：云 ASR 失败 → 提示并回退本地（若已装模型）；整理失败 → 用原文

### 4.4 状态机

`idle → recording → transcribing → polishing → injecting → idle`（任意环节异常 → `error` 显示 1.2s → `idle`）
- `recording` 期间再次按下忽略；`max_record_seconds`（默认 25s）到点自动停止
- 录音过短（<0.3s）或 RMS < 0.0015 → 忽略并回 idle（沿用 Python 版实测阈值）

## 5. 关键设计要点

1. **热键不吞键**：钩子回调一律 `CallNextHookEx`，仅记录 F9（`VK_F9=0x78`）的 down/up 与 Shift 状态；`Shift+F9` 走"取原文"分支。
2. **音频**：按设备默认配置打开（不强行 16k，避免 `Invalid sample rate`），回调里多声道→单声道→`rubato` 重采样到 16k；录音期间累计到上限即截断。
3. **模型管理**：`models/sense-voice/{model.int8.onnx, tokens.txt}`；缺失时托盘菜单触发下载（hf-mirror → modelscope），显示进度；也支持手动拷贝（同事之间传 U 盘）。
4. **配置热切换**：托盘菜单改动立即写回 `config.toml` 并生效；其余项（热键、录音上限）重启生效，README 说明。
5. **注入细节**：先存旧剪贴板 → 写新文本 → 250ms → 发 Ctrl+V → 600ms → 恢复旧剪贴板（仅文本）；`Shift+F9` = Ctrl+Z + 粘贴 ASR 原文。
6. **管理员窗口无法注入**（Windows UIPI 限制，与 Python 版一致），文档写明。
7. **单实例**：命名互斥体，二次启动提示"已在运行"并退出（避免双钩子双托盘）。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| sherpa-onnx 静态库体积大（win 静态归档 117MB 压缩） | 二进制可能 30~60MB | M5 实测：超 35MB 改 `shared` 动态链接（随包 DLL） |
| build 脚本联网下载预编译库 | 国内构建慢/失败 | 预下载归档 + `SHERPA_ONNX_ARCHIVE_DIR`；或走 ghproxy 镜像 |
| Linux Wayland 热键受限（X11 才能全局抓键） | Linux 体验受损 | 降级：托盘点击开始/停止；文档说明；二期评估 `libei`/portal |
| macOS 权限链（辅助功能/输入监控）+ 未签名 | 首次使用需手动授权；更新后授权可能失效 | 引导 UI + 文档；正式分发再买开发者账号做签名公证 |
| 自写钩子稳定性（Windows 钩子被系统摘除） | 热键失效 | 钩子线程带看门狗（定期 `SendMessage` 自检，失效自动重装）+ 日志 |
| 模型下载源被墙/慢 | 首次使用失败 | hf-mirror → modelscope 双源 + 手动放置 + 断点续传 |
| 云后端隐私（语音出本机） | 公司合规 | 默认本地；云为显式开关；文档标注"语音将上传到所填地址" |
