### 1.2 追加：Win+H 热键支持（2026-09-25）

**需求**：主热键支持 `win+h` 等修饰键组合（grill 定稿 6 问：通用 win+<键> / 精确匹配 / 取原文=主键修饰+Shift / 保存校验+启动容错 / 单测+合成按键+实测 / 验证后出包）。

**实现**（仅 app 侧，fork 无改动、无 git 动作）：
- `src/hotkey/mod.rs`：解析 `[修饰+]*键`（win/meta/super/ctrl/alt/shift 可组合）；字母键须带修饰键；
  主键禁 Shift（含 left/right_shift 作主键）；新增 `classify()` 纯函数（**精确匹配**：写了的按住、没写的没按；
  取原文 = 主键修饰 + Shift）；主键自身是 ctrl/alt 键（如 right_alt）时该修饰位两侧排除
- `src/hotkey/windows.rs`：`read_mods()` 读左右 win/ctrl/alt/shift 状态；**钩子回调内零日志**
  （LL 钩子回调超时会被系统静默摘钩）；顺带修掉「看门狗每 60s 重装钩子会把运行时切换的热键改回启动值」旧 bug
- `src/gui.rs`：保存前校验热键（无效拒绝保存+状态栏提示）；事件日志移到 `pump`（普通线程，安全）
- `src/main.rs`：启动容错——热键无效回退 f9 + WARN，不再起不来
- `config.default.toml` / `README.md`：语法、行为变化（ctrl+f9 不再误触发）与限制说明

**验证**：
- 单测 11/11（win+h / meta 别名 / 非法输入拒绝 / 精确匹配 / right_alt 作主键 / f9 回归）
- 合成按键（记事本聚焦）10/10：`win+h`=Press+Release、`win+shift+h`=Raw、`ctrl+win+h` 与裸 `h` 无事件、`f9` 回归、`ctrl+f9` 无事件
- 启动容错：坏热键（win+q1）→ WARN 回退 f9、进程正常启动

**已知 Windows 限制（非 bug，无法用钩子规避）**：焦点在本程序自己的设置窗口上时，系统**不调用该进程的
低级键盘钩子**（输入目标是钩子进程自己的窗口时系统跳过该钩子；SO: "WH_KEYBOARD_LL hook doesn't capture
input in own process"）——即设置窗在前台且聚焦时热键不响应；设置窗隐藏到托盘（常态）或焦点在其他应用时正常。

**用法**：设置窗 → 通用 → 主热键填 `win+h` → 保存并应用（立即生效）。前提：关掉系统听写（否则两个都触发）。

## 4. 环境坑（沿用 + 本会话新增）

- `.rc` 是 UTF-16LE+CRLF：内置 read/edit 工具读不了（ripgrep 反而能搜）；只能脚本改，且脚本由 kevin 跑（dcg 规则）
- **字形陷阱**：`输/輸`、`倾/傾`、`听/聽` 在 grep 输出里看着像，改前/改后用 python 核 codepoints
- dcg 会拦：反引号命令、`powershell -File`、批量 `.rc` 修改 → **停下问 kevin**，不得绕过
- Weasel exe 的版本资源 `FileVersionInfo` 读不到（上游固有，官方包同样）
- AI Voice 模型 junction：`K:\AI_Voice_rs\target\release\models` → `models`（`cargo clean` 后会丢，需重建）
- **新增 · 构建产物过期陷阱**：增量构建只认文件时间戳——18:35 的产物早于 21:53–21:59 的改名改动，必须重编；动手前先核对 `.rc`/源码 mtime vs 产物 mtime
- **新增 · `output\README.txt` 是构建产物**：`build.bat :build_data` 才会从 `README.md` 生成；只跑 `weasel` 目标不会更新它。改 README 后要手动 `Copy-Item README.md output\README.txt` 再重出 NSIS
- **新增 · Rust format 占位符不落盘**：`println!("倾听输入法: {}", …)` 在二进制里只存字面片段 `倾听输入法: `，字节校验别查 `倾听输入法: {}`
- **新增 · Inno 升级沿用旧目录**：kevin 旧装目录 `K:\app\AIVoice\`（自定义过），升级默认沿用并保留 `config.toml`
- **新增 · app 不自动换 IME 名**：`rime_deploy_logged` 仅在「weasel 未安装」时静默装 fork；已装官方小狼毫时不会重装 → 需手动跑一次 fork 安装器（§5.2）
