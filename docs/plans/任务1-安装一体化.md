## 0. 一句话目标

用户**只跑一次** `listen-0.1.0-setup.exe`：装 listen + **静默安装/替换倾听输入法（fork）** + 铺 Rime 资源 + **自带 ASR 模型**。
全程**一次 UAC、零手动步骤、零首次下载**；重启一次后语音与键盘全部可用。

## 2. 设计

### 2.1 目标安装时序（单 UAC）

```
1. 用户双击 listen-0.1.0-setup.exe → Inno（admin，唯一一次 UAC）
2. 落盘：listen.exe + resources\rime\（方案包 + 语法模型 + fork 安装器）+ models\sense-voice\（230MB）
3. [Run] 静默跑 fork 安装器 /S（waituntilterminated，runhidden）
   └─ 已是同一 fork 构建 → 跳过（见 2.2 判定）
4. [Run] listen.exe --first-run（runasoriginaluser，原用户身份）
   └─ 首启向导选语言 → 铺方案包 → 部署（提权）
5. 完成页：提示「输入法已更新，请重启一次」+ 一键重启
```

### 2.2 关键改动点

**listen.iss（installer\listen.iss）**

| 改动 | 说明 |
|------|------|
| 新增 `/DIncludeModel`（默认 1） | `#if IncludeModel` 包住 `[Files]` 的 `models\sense-voice\* → {app}\models\sense-voice`（约 230MB） |
| `[Run]` 新增 fork 安装器 | `Filename: "{app}\resources\rime\weasel-0.17.4.0-installer.exe"; Parameters: "/S"; StatusMsg: "正在安装倾听输入法（键盘输入）…"; Flags: runhidden waituntilterminated` |
| 跳过已装同版 fork | `[Code]` 读 fork 标记（见下），与编译期常量 `/DForkBuild=<id>` 比较，相同则 `[Run]` 条目不执行（用 `Check: ShouldInstallFork`） |
| 完成页重启提示 | `CurStepChanged(ssDone)`：若本次装了/升级了 IME → 提示重启（Inno 重启复选框或 `Reboot()` 确认框） |
| 体积打印 | 现有 build.ps1 已有 |

**fork 标记（配套 fork 侧小改，随任务 2 一起出包）**

- fork 的 `output\install.nsi` 安装末尾写注册表 `HKLM\Software\K3R\ListenIME`：`ForkBuild` = 构建标识（用包内 WeaselServer.exe 的 SHA256 前 16 位或构建日期戳）
- Inno `[Code]` 读该值，与本次捆绑包的 `ForkBuild` 常量一致 → 跳过重装（避免每次升级 app 都强制重启）
- 若不一致或不存在（含官方小狼毫/旧版）→ 执行 `/S` 安装（自动卸载替换）

**build.ps1（installer\build.ps1）**

| 改动 | 说明 |
|------|------|
| `-Setup` 默认传 `/DIncludeModel=1` | 全量离线版为默认；同时计算并传 `/DForkBuild=<包内 WeaselServer.exe SHA 前16>` |
| 新增 `-NoModel` | 传 `/DIncludeModel=0`（轻量变体，模型仍首次运行下载） |
| 构建前校验 | `models\sense-voice\model.int8.onnx` + `tokens.txt` 必须存在（缺则报错提示先下载） |

**应用侧（最小改动）**

- `rime/mod.rs`：可选加固——`detect()` 增加"是否我们的 fork"判定（比对 `ForkBuild` 注册表值），首启向导文案区分「已安装（倾听输入法）」/「检测到其他输入法」；安装逻辑保持不变（作为兜底）
- 模型已随包 → 首启不再触发下载（现有"存在即跳过"逻辑已覆盖）
- 无需改 `--rime-deploy`/部署链路

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| 静默装 fork 被杀软拦截/失败 | Inno 记录退出码；完成页提示；app 首启兜底重试（现有 `--rime-install` 链路保留） |
| Inno（admin）里跑 NSIS 的身份/交互问题 | 子进程继承 admin，无二次 UAC；S1 实测确认；`--first-run` 用 `runasoriginaluser` 保证 listen 是普通用户身份 |
| 升级强制重启（每次 app 更新都重装 IME） | `ForkBuild` 标记跳过同版；仅 IME 有更新时提示重启 |
| 安装包 ~625MB 分发不便 | 保留 `-NoModel`/`-NoLM` 变体；国内网盘/U 盘分发 |
| 用户忽略重启 → IME dll 被占用 | 完成页强提示；app 启动时检测 IME 版本不匹配再提示一次 |
| 老用户自定义安装目录/升级路径 | 沿用现有 `InstallDirRegKey` 行为；S7 覆盖测试 |
| 语法模型 400MB 让"全量"过大 | `-NoLM` 组合可选（默认仍含，符合"全量离线"诉求） |
