## 0. 一句话目标

语音输入时桌面出现**悬浮小窗**：实时显示状态/计时 + 最近 N 段「原文行 + 整理行」，供开发期直观检验"语音智能整理"质量；

## 2. 详细设计

### 2.1 悬浮窗（listen 侧）

**形态**：eframe 多视口（同进程），`ViewportBuilder::with_decorations(false).with_always_on_top().with_transparent(true).with_taskbar(false)`，不激活焦点（`with_active(false)`）。
默认位置：当前显示器底部居中；拖动后记忆（存 config）；简版不做多显示器精调。

**内容布局（示意）**：

```
● 识别中  00:37
──────────────────────────────
「我觉得这个 nRF52832 的 SAADC 采样有点问题」      ← 原文行（白/浅灰）
「我觉得 nRF52832 的 SAADC 采样有点问题。」        ← 整理行（青色，仅整理开启）
──────────────────────────────
（上一段……）
```

- 状态行：● 录音中/识别中/整理中/注入中/错误（state.rs 直接映射）+ 会话计时（Recording 起算）
- 文本区：最近 N 段，每段"原文行 + 整理行"；每行超"最大字数"则截断加省略号（0=不截断）
- 生命周期：会话开始出现；会话结束**延迟 hide_delay_seconds 后隐藏**（默认 5s，可调）

**事件流（新增，main.rs `Evt`）**：
- `Evt::Segment { text: String }`：`process_segment` 里 ASR 文本产出时发送（原文）
- `Evt::Polished { text: String }`：`flush_pending` 里整理完成时发送（批次文本；整理关闭时不发）
- （可选）`Evt::Level(f32)`：音量条（本次可不做，YAGNI）

**设置（新增「悬浮窗」分区）**：
| 项 | 范围/默认 |
|----|----------|
| 显示悬浮窗 | 开/关（默认开） |
| 字号 | 12~32，默认 16 |
| 保留段数 | 1~10，默认 3 |
| 每行最大字数 | 0~200，默认 60（0=不截断） |
| 结束隐藏延迟 | 1~60 秒，默认 5 |

### 2.2 语音引擎总开关

**设置窗顶部"语音引擎"状态卡**（始终可见）：
- 状态点 + 文案：`就绪 / 已挂起 / 启动中 / 未运行 / 已关闭`（实时刷新）
- 「启用语音输入」开关（持久化 `general.voice_enabled`，默认 true）
- 摘要行：识别后端（本地/云端）· 整理档位

**语义（总开关）**：
- **OFF**：引擎停止（卸 ASR 模型、摘热键钩子；**进程保留**以便继续操作设置窗），状态=`disabled`；
  托管侧（fork）**不再拉起**；**不启动挂起超时自动退计时**（避免设置窗被自动退出）
- **ON**：恢复；切到倾听输入法时由 fork 正常自动拉起
- 独立模式同样遵守该开关

**机制**：
- 持久化：`config.toml [general] voice_enabled`（listen 侧读写）
- **标志文件**：listen.exe 同级 `voice_off.flag`（listen 在开关变化/启动时同步写/删）——给 fork 判断用
- ListenCtl `STATUS` 增加状态值 `disabled`（fork 托盘映射为「已关闭」）

**fork 侧改动（小）**：
1. `OnImeActiveChanged(true)` → spawn 前检查 `voice_off.flag`：存在则跳过（记日志）
2. 托盘子菜单状态映射：`disabled` → 「已关闭」

### 2.3 配置新增

```toml
[general]
voice_enabled = true          # 语音引擎总开关（默认 true）

[floating]
enabled = true                # 悬浮窗显示开关
font_size = 16                # 字号 12~32
history = 3                   # 保留段数 1~10
max_chars = 60                # 每行最大字数，0=不截断
hide_delay_seconds = 5        # 会话结束隐藏延迟（1~60）
pos_x = -1                    # 拖动记忆（-1 = 未设置，用默认底部居中）
pos_y = -1
```
